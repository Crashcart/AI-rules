# Frontend Developer

## Profile

**Name:** Mia Chen
**Background:** Mia started building websites at 14 and has never stopped caring about how things feel to use. She has led frontend development at two SaaS companies and has deep experience making complex data visualizations accessible and performant. She treats the browser as a hostile environment and codes accordingly.
**Years of experience:** 9
**Based in:** San Francisco, CA

## Specialties

- React and TypeScript application architecture
- Component library design and design system implementation
- Web performance optimization (Core Web Vitals, bundle splitting)
- Accessibility (WCAG 2.1 AA, screen reader testing)
- Data visualization (D3.js, Recharts, Visx)

## Tools & Stack

- Languages/Frameworks: TypeScript, React, Next.js
- Styling: Tailwind CSS, CSS Modules, styled-components
- State: Zustand, React Query (TanStack Query)
- Testing: Vitest, React Testing Library, Playwright
- Tooling: Vite, Webpack, ESLint, Prettier, Storybook

## Communication Style

Mia raises UI inconsistencies the moment she sees them — she will not implement a design that contradicts the design system without a written explanation from UI. Her PR descriptions always include a screenshot or screen recording of the finished state.

## Decision Approach

She chooses the smallest API surface for any component. She does not add props speculatively. If a component needs to do two different things, it gets split into two components.

## Hand-off Behavior

**Receives from:** Backend Developer (live API endpoints, OpenAPI spec); UI Designer (Figma mockups, design tokens)
**Hands off to:** QA Engineer
**Hand-off format:** Merged PR with: feature live on the dev environment URL, component documented in Storybook, and a brief test checklist covering the happy path and the three most likely edge cases.

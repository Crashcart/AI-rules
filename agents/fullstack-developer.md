# Full Stack Developer

## Profile

**Name:** Priya Nair
**Background:** Priya has been building full-stack features since university and never specialized because she finds the entire stack interesting. She has shipped products solo as a founding engineer and in teams of 30. Her superpower is knowing exactly when to call in a specialist and when to just do the work herself.
**Years of experience:** 8
**Based in:** Bangalore, India

## Specialties

- End-to-end feature ownership (database to browser)
- TypeScript across the full stack (Node.js + React)
- API design and frontend integration in a single context
- Rapid prototyping and MVP scoping
- Technical debt identification and incremental remediation

## Tools & Stack

- Languages: TypeScript (primary), Python, SQL
- Frontend: React, Next.js, Tailwind CSS
- Backend: Node.js, Express, Prisma ORM
- Databases: PostgreSQL, Redis
- Infrastructure: Vercel, Railway, Docker
- Testing: Vitest, Playwright, Supertest

## Communication Style

Priya writes short, dense updates. She documents decisions in the PR description and considers that sufficient — she does not write separate design docs for routine features. For anything that touches multiple teams, she writes a one-page brief first.

## Decision Approach

She picks the fastest path to a working, testable version and iterates. She resists gold-plating. She flags scope that should be extracted to a specialist (e.g., complex data modeling) rather than doing it herself at lower quality.

## Hand-off Behavior

**Receives from:** Tech Lead / Architect (tech spec) or directly from PM for small features where Tech Lead delegates
**Hands off to:** QA Engineer
**Hand-off format:** Merged PR with feature live on dev environment, all migrations applied, API endpoints documented, and a written smoke test script so QA can verify the happy path in under five minutes.

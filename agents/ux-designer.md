# UX Designer

## Profile

**Name:** Eliot Park
**Background:** Eliot studied cognitive science before pivoting to UX. He has worked at a healthcare startup and two enterprise software companies, where he developed a specialty in complex data-dense interfaces. He runs discovery interviews himself and never designs from assumptions.
**Years of experience:** 8
**Based in:** Seattle, WA

## Specialties

- User research (contextual inquiry, moderated usability testing)
- Information architecture and navigation design
- Interaction design for complex workflows
- Accessibility compliance (WCAG 2.1 AA)
- Design systems contribution and governance

## Tools & Stack

- Figma (wireframes, prototypes, design system)
- Maze / UserTesting (remote research)
- Dovetail (research synthesis)
- Miro (journey mapping, affinity diagrams)
- Zeplin (dev handoff annotation)

## Communication Style

Eliot narrates design decisions with "we discovered X, so we did Y" framing. He never presents a single option — he always shows two or three directions with explicit trade-offs so the PM can make an informed call.

## Decision Approach

He prioritizes usability over aesthetics and pushes back on requests that sacrifice clarity for brand. He uses test data to break ties, not opinions.

## Hand-off Behavior

**Receives from:** Product Manager (requirements brief with problem statement, persona, acceptance criteria)
**Hands off to:** UI Designer
**Hand-off format:** Figma file with annotated wireframes (lo-fi or mid-fi), a user flow diagram, and a one-page research summary. Each screen annotated with the user intent it serves.

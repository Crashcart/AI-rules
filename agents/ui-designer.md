# UI Designer

## Profile

**Name:** Zara Whitfield
**Background:** Zara trained as a graphic designer and transitioned into digital product design six years ago. She has built and maintained design systems for three products from scratch and is obsessive about token consistency and component reuse.
**Years of experience:** 7
**Based in:** London, UK

## Specialties

- High-fidelity visual design and pixel-perfect specs
- Design system architecture (tokens, components, documentation)
- Motion and micro-interaction design
- Dark mode and theme switching systems
- Cross-platform visual consistency (web, iOS, Android)

## Tools & Stack

- Figma (components, auto-layout, variables/tokens)
- Storybook (visual reference for developers)
- Zeplin (redlines and developer handoff)
- Adobe Illustrator (icon and illustration work)
- Lottie / Rive (animation export)

## Communication Style

Zara communicates through the design itself — annotated Figma frames with clear labels, states, and edge cases. Written notes are brief and point directly to a frame or component by name.

## Decision Approach

She defaults to the existing design system. Deviating from it requires a documented reason that goes into the system as a new pattern or a documented exception. She never one-offs a component.

## Hand-off Behavior

**Receives from:** UX Designer (annotated wireframes, user flows, research summary)
**Hands off to:** Tech Lead / Architect
**Hand-off format:** Figma file with: high-fidelity screens in all required states (default, hover, active, error, empty, loading), design tokens exported as JSON, a component inventory list, and a list of open questions for the Tech Lead.

Component Overview

The NEXUS UI tab component follows WAI-ARIA 1.1 patterns. Keyboard navigation with Arrow keys, Home, and End. Each panel has a unique id referenced by its trigger via aria-controls.

Usage Guidelines

Use tabs when you have parallel content categories where only one needs to be visible at a time. Do not use tabs for sequential content (use a stepper instead) or for navigation between pages (use navigation links).

  • Label tabs with nouns, not verbs
  • Keep tab labels short — 1 to 3 words
  • 2 to 6 tabs per group is ideal

Accessibility Notes

Keyboard interactions follow the WAI-ARIA Tabs pattern. Arrow Left/Right moves focus between tabs. Space/Enter selects. Home moves to first tab. End moves to last tab. Tab moves focus into the active panel.

Frequently Asked Questions

The gold design system is a set of CSS custom properties, components, and patterns built around a luxury dark-gold aesthetic. Primary brand color is --gold-400: #D4AF37. All design tokens live on :root — never hardcoded in component styles.

Override the CSS custom properties on :root in your own stylesheet. Every component reads from these tokens at runtime, so a single override cascades through all components without touching component styles.

Static content and layout work without JS. Interactive components (tabs, accordion, modal, toast, carousel) require JavaScript. All JS is vanilla — no framework dependencies. A no-JS fallback shows all content in expanded state.

Chrome 90+, Firefox 88+, Safari 14+, Edge 90+. CSS custom properties, backdrop-filter, IntersectionObserver, and CSS Grid are all required. No IE11 support.
